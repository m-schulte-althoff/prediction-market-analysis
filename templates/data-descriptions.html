02

What is being measured?

The study separates a comparison between contracts, a question about a rule given specified information, and an automated description of the text.

Between contracts

Payoff divergence

Two contracts assign different normalized settlements to at least one explicitly specified scenario. A separating scenario establishes non-equivalence over the audited domain; it does not measure frequency or economic magnitude.

Within a contract

Written-rule determinacy

Given a rule version and stated information, is the payout fixed? Record any remaining fact, reference price, interpretation or authority decision. Later adjudication can supply a required input.

Descriptive text proxy

Rule-text specificity

An exploratory equal-weight average of five literal text components. The legacy field is determinacy_score. It has no independent human construct validation and does not establish a payout mapping.

qc = Eμ[rc]   Expected normalized payout depends on the settlement mapping, including fractional amounts. It is not automatically an observed market price.

Why this matters for the study

A contract count is not a rule-design count

Threshold ladders and other families can repeat the same rule template across many contracts. A large family can therefore contribute heavily to an overall text-feature mean.

The supplementary activity analysis uses platform-qualified family clusters for its preferred uncertainty estimate. It remains an association in selected portfolios; it does not identify a causal effect of specificity on trading.

Volume is the platform-reported cumulative field. Platform units and acquisition selection differ; pooled volume totals are not used here as comparable dollar turnover.

What counts as outcome evidence?

A recorded platform result, an endpoint price and a fractional settlement convey different information. The ledger keeps those categories separate.

$outcomes_table

Polymarket endpoint inference with resolved or settled status is distinguished from proposed or missing-status inference. An intermediate price is not converted to a binary outcome. Kalshi scalar settlements remain separate from recorded YES/NO results.

How to reproduce this page

From the repository root, with the existing processed archives available:

uv run python3 main.py describe

The command reads local data, regenerates this page, and writes descriptive CSV tables and standalone SVG figures. It performs no acquisition or model fitting. The HTML embeds all charts and styling, so the page remains readable when shared alone; relative source and download links require the repository output files.

Graph percentages use within-platform denominators. IQR is the 25th–75th percentile. Components and the composite range from 0 to 1. No inferred population estimates or new construct-validation scores are introduced.
